# 約分マスター・クラッシュ！

次々に現れる分数の中から、「約分できる分数」をすばやく見抜いてタップする、判断スピード型の約分練習ゲームです。

## 公開ページ

[GitHub Pagesで開く](https://tt-sensei.github.io/yakubuncrash/)

## 遊び方

- 分数が画面に現れている間に、約分できるものをタップして消す
- 約分できない分数をタップするとミス
- 約分できる分数を見逃してもミス
- 連続して正しく消すとコンボになり、スコアが伸びる
- スコアに応じて称号が変わり、バッジが解放される

## 対象

小学校5年生中心（分数の約分）。

「約分クロスバスターズ」（yakubunslash）がペアと割る数を選んで約分する形式なのに対し、こちらは「約分できるかどうかを見抜く」判断に特化した形式です。

## 技術メモ

- `index.html` の単一ファイルで動作し、ビルド不要
- 外部APIなどの外部通信なし（ブラウザだけで動作）
- バッジなどの記録は端末内（localStorage）に保存
